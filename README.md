Midnight Skillet — an original late-night diner cooking game that plays offline in a desktop browser from static files. Take tickets off the order board, grab ingredients from the crates, chop on the board, grill patties and eggs (careful: they burn), assemble plates that match a recipe, and serve before each customer's patience runs out. Six recipes, a 150-second shift clock, speed tips, and walkouts that end the night early. Mouse or keyboard (1–8 crates, C board, G grill, Q/W plates, Enter serve). All art is drawn in code and all sound is synthesized with WebAudio — no assets, no network.

## Run it

```sh
node main.ts            # hands the game in: writes game/, screenshots/ and dossier.json to /output (or $MAKEFUN_OUTPUT_DIR)
# to play: serve the game/ folder with any static file server and open index.html in a desktop browser
```
